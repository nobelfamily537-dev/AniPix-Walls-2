# AniPix-Walls-2

Wallpaper image files for the AniPix app - volume 2.

The index (`wallpapers.json`) lives in [AniPix-Walls](https://github.com/nobelfamily537-dev/AniPix-Walls).
This repository holds only image files, so the library can keep growing after
volume 1 hit GitHub's size guidance.

Layout is the same as volume 1:

    anime/<id>.webp
    anime/<id>_thumb.webp
    anime2/...
    game/...
    god/...
    nature/...
    space/...

Served through jsDelivr:

    https://cdn.jsdelivr.net/gh/nobelfamily537-dev/AniPix-Walls-2@main/<category>/<id>.webp

Images are WebP quality 85, full size 1080x1920, thumbnails 360x640.
